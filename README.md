Requires Node 22.18+ (executed in the `node22` sandbox):

```bash

```

Writes a deterministic UTF-8 text artifact (`1..400` characters) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when testing locally).
